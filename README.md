# 🛒 مشروع التجارة الإلكترونية

[![عرض الموقع](https://img.shields.io/badge/عرض_الموقع-زيارة_الموقع-blue)](https://e-commerce-project-two-sandy.vercel.app)

## 📖 نبذة عن المشروع

مشروع **التجارة الإلكترونية** هو تطبيق ويب يهدف إلى توفير منصة للمستخدمين لشراء المنتجات عبر الإنترنت بسهولة وأمان. يعتمد المشروع على تقنيات حديثة لضمان تجربة مستخدم مميزة.

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - [Angular](https://angular.io/): إطار عمل لبناء تطبيقات ويب تفاعلية.
  - [Tailwind CSS](https://tailwindcss.com/): إطار عمل لتصميم الواجهات بأسلوب مرن وسهل الاستخدام.

- **التكاملات:**
  - [Stripe](https://stripe.com/): بوابة دفع آمنة لمعالجة المدفوعات الإلكترونية.

## 🚀 الميزات الرئيسية

- **تصفح المنتجات:** يمكن للمستخدمين استعراض مجموعة متنوعة من المنتجات مع تفاصيلها.
- **إضافة إلى السلة:** إمكانية إضافة المنتجات إلى سلة التسوق.
- **معالجة الدفع:** نظام دفع آمن وسهل الاستخدام باستخدام Stripe.
- **استجابة عالية:** تصميم متجاوب يعمل بشكل مثالي على مختلف الأجهزة.

## 🛡️ الأمان

تم تطبيق أفضل ممارسات الأمان لضمان حماية بيانات المستخدمين والمعاملات المالية.

- حساب على [Stripe](https://stripe.com/) للحصول على مفاتيح API.
